# Dataset `cpi_u_nsa_v2` (module `cpi_u_nsa`)

Monthly CPI-U NSA (`CUUR0000SA0` / ALFRED `CPIAUCNS`), 1982-84=100. Each reference month retains its first observable value and changed later vintages; unchanged republications are counted. Exact `release_date` is unknown and NULL; the actual source `vintage_date` is retained for both original and revision rows. Earlier history remains for deflation lookbacks.

Schema `atx.alpha-panel.cpi-u-nsa/v2`; rule `cpi-u-nsa-vintage-v2`; clock `alfred-vintage-bound-v2`; staleness 100 days from reference-month end. Clock delivery is **PARTIAL**, independently of C5/hash/partition acceptance.

Controller CPI-1 permits a conservative bound when a dated source proves civil-date availability. [ALFRED download help](https://alfred.stlouisfed.org/help/downloaddata) defines vintage data as it existed on that past date. The landed, hash-verified response supplies this premise for original and revised vintage columns. [ALFRED help](https://alfred.stlouisfed.org/help) explains dates may come from the original source, provider, or first FRED availability; they do not prove an intraday release instant.

With that verified premise, `available_at` is 00:00 UTC two calendar days after `vintage_date`, `clock_basis=alfred_civil_date_plus_two_days_utc_bound`. Proof: the latest end of civil date D over UTC offsets -12..+14 is D+1 12:00 UTC, earlier than D+2 00:00 UTC. The bound handles original releases, archival revisions, DST and year rollover without guessing 08:30. If the source premise is absent, the builder uses the actual response-observation instant (`response_observed_at_historical_timing_unavailable`). Request-start `fetched_at` alone is insufficient; older response filenames contain their post-retrieval timestamps. Historical timing is then unavailable. Manifest `clock_evidence` records which path was proved.

Parts are `cpi_u_nsa_v2/parts/year=YYYY/cpi_u_nsa.parquet`, partitioned by available_at UTC year. The atomic manifest pins every part, raw input, clock-semantic evidence, code and receipt ledger. `python -m atx_db.alpha_panel.cpi_u_nsa build` defaults to the new stage, then `accept`; run all real data jobs through the shared heavy memory guard. Existing nonempty stages cannot be overwritten. Registry stub: `cpi_u_nsa_v2.registry.json`.

The immutable legacy `cpi_u_nsa` artifact and its original manifest pin `06a63d16a43a9c821f213bf819b7a0971bc71b796536305ede9fa9dadb26d6e6` remain for provenance, with a read-only registry declaration. Its 08:30 clocks are unproved and superseded by the new stage; legacy C5/hash PASS does not approve those timestamps.

All 224 requested vintages since 2008 were landed. The network client allows HTTPS only on named ALFRED/FRED/BLS hosts, >=1.1-second spacing, no redirects, and counts every attempt/error cumulatively. Clock evidence used the final two requests; budget is now **30/30**, with no further requests allowed. Reference coverage ends 2026-08, source vintage ends 2026-09-11; October 2025 is absent in ALFRED and blank in FRED/BLS. Coverage of 2025/2026 is partial. Values retain 227 rows (223 first releases, 4 archival revisions); cross-checks show no mismatches. Exact corrected pins/commands/prints are in [B3 acceptance](../p9-al-data/b3-acceptance.md).

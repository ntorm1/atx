# Dataset `cpi_u_nsa`

Monthly CPI-U, U.S. city average, all items, not seasonally adjusted: BLS `CUUR0000SA0`, ALFRED/FRED `CPIAUCNS`, index level 1982-84=100. ALFRED download-page vintage dates and actual archival CSV columns provide the dated source. FRED latest and keyless BLS API are value cross-checks only; FRED graph requests with vintage_date were found to ignore it and provide no vintage proof.

Schema `atx.alpha-panel.cpi-u-nsa/v1`; rule `cpi-u-nsa-vintage-v1`; clock `alfred-vintage-date-0830-et-v1`; staleness 100 days from reference-month end. `available_at` converts 08:30 America/New_York on the ALFRED vintage date to naive UTC, including DST. `clock_basis=alfred_vintage_date_0830_et` identifies that evidence, rather than an independently obtained BLS release schedule. ALFRED vintage dates are the authoritative dated alternative expressly allowed by Task 8. Dates identify publication/revision vintages; later archival corrections are preserved.

Each reference month gets its first observable release and every changed later value, keyed by (ref_month, vintage_date). Unchanged republications are counted without adding a row; no vintage is overwritten. A month present in the first selected vintage is excluded because its release cannot be observed. Missing months and vanished values are explicit. Parts are `parts/year=YYYY/cpi_u_nsa.parquet` by available_at year. The atomic manifest pins all parts, raw inputs, code identity and receipt ledger. Existing output is immutable.

Run `python -m atx_db.alpha_panel.cpi_u_nsa download`, `build`, and `accept`, each under the heavy memory guard. Download reuses verified receipts, prioritizes 2020+ vintages, honors the server's 12-line cap and stops on no progress. All HTTP attempts, including errors/timeouts, count cumulatively toward 30; requests are spaced >=1.1 seconds, HTTPS to named ALFRED/FRED/BLS hosts only, without redirects.

Measured: 28/30 attempts used, all 224 requested vintages from 2008 onward landed; 227 output rows (223 first releases, 4 revisions), 19 parts. Primary 2020+ coverage has 79 reference months through 2026-08, latest vintage 2026-09-11. October 2025 is missing in ALFRED and blank in both cross-checks; 2025 and 2026 coverage are partial. FRED agrees on 223 months and BLS on 31, with zero mismatches. Earlier history remains for deflation lookbacks. See [B3 acceptance](../p9-al-data/b3-acceptance.md) for all measured rows and hashes.

## Composites

- Per formation each constituent is a cross-sectional z; a class composite is the weighted mean over names with at least 50% of the class weight valued, re-standardized; the across-class composite combines class composites the same way.
- Weightings: `equal`, `ic_shrunk`; `ic_shrunk` = (1 - s) x positive-IC share + s / k with s = 0.5 (IC: mean monthly rank IC at 3 months on the fit sample).
- Emitted: within-class composites of classes with >= 2 constituents (`cmp_<class>_eq` / `_icw`), across classes when >= 2 classes (`cmp_classes_eq` / `_icw`); a duplicate of a signal in another class is left out.
- Storage: an R2b-shaped feature version (store schema 3, class `composite`, constituents and weights in the catalog row) evaluated once by the R3b harness; one composite build and one holdout evaluation per R4 ledger.

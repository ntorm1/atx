# Gold alpha panel production contract

The warehouse builds daily cross-sectional research features for 2020-2026. A feature passing the selection screen is a candidate; predictive quality requires separate validation evidence. No production IC or admission count is claimed until the refreshed silver build and evaluation complete.

The existing characteristics registry contains 100 prior-signed signals and controls. `characteristics.py` computes trailing return, risk, liquidity, options, ownership, event and accounting measures. Set `ATX_ALPHA_PANEL_STAGE=panel_goldready` to bind the refreshed point-in-time silver panel. The legacy panel uses historical snapshot identity backfills and must not supply the new release. The characteristics manifest binds the actual source manifest hashes; historical data before 2020 supply trailing warmup and 2019 discovery confirmation.

`gold.py` requires the evaluator's strict observed-return labels, purged 2020-2021 SELECTION summaries, and SELECTION-only pairwise redundancy. Admission requires mean daily coverage of at least 50% over 2019-2021, at least 30% in each of those years, positive prior-signed IC and Newey-West t at least 2.5 for a fixed horizon among 5, 21 and 63 sessions, and positive 2019 discovery IC for the same raw or industry-neutral variant. Candidates are walked by decreasing selection t and rejected at absolute pair correlation of 0.90 or more. Missing correlation evidence fails admission. The selected horizon and variant are frozen in `selection.json`. Coverage after 2021 and validation returns in 2022-2023 cannot alter admission. Controls are always shipped separately.

Scores use the current session's `member_equity` cross section: 1/99 percentile winsorization, average-tie ranks, inverse-normal transformation, then centering and unit population standard deviation. The industry variant additionally demeans FF49 groups containing at least three finite values. Constant cross sections are null. Event missing values become zero only when the registry explicitly specifies `fill_zero`. Family composites require at least two admitted signals, use an equal-weight mean when at least half are present, and are standardized again. `c_all` requires at least three available family composites. Composites combine the frozen selected horizons and are evaluated independently at all three horizons; they are not automatically certified alpha models.

The output contains only eligible equity members, keyed by `(session_date, security_id)`, with CIK, FF49/FF12, `g_*` scores, `c_*` composites and `ctl_*` raw controls. Year files are written atomically; a complete manifest is published last with source, selection and evaluation hashes. Gold publication refuses evidence tied to different current feature, panel or label manifests. Daily joins check unique keys and complete membership alignment. If no candidate passes, the admission audit is written and no complete gold panel is published.

The owner's subsequent instruction on 2026-10-01 authorizes evaluation of frozen features on 2024-2026. `gold/frozen_recipe.json`, bound by the gold manifest, predeclares the exact selected score columns, selected horizons and variants, prior signs, composite weights, missing-component rules, normalization and evaluation horizons. The separate freeze/evaluation workflow must pin this recipe, physical gold files and construction code before any out-of-sample return is read. Out-of-sample results cannot change selection, horizons, signs or weights. This authorization does not change the consumer export's default 2024-01-01 seal.

Source qualifications remain explicit. Vendor historical price and identity vintages are unverified; repaired zero-ID lines can depend on later ticker brackets. The panel's `shares_out` is a lag-90 restated vendor observation adjusted using past split basis, and market-equity measures inherit that uncertainty. Options use previous-session IV to respect delivery timing, but snapshot vintages remain unverified. Borrow inputs are proxies rather than observed fees. Gold manifests carry feature-level flags and `source_vintages_certified=false`; selection t alone never sets `predictive_power_certified=true`.

Zero-ID repaired observations are quarantined causally. A sparse backward ASOF lookup finds the most recent repaired date of each line using only dates up to the current decision session. Calendar-session index age, rather than the number of observed line rows, sets the quarantine to the registry's longest lookback (1260 sessions). Repaired current numeric observations, including borrow proxies and long-history returns, cannot feed feature windows. Signals and controls remain null while the trailing quarantine is active; industry means exclude those lines. Gold excludes repaired decision rows and retains other quarantined rows with null scores. Event zero fill cannot restore quarantined observations. Extraction receipts report current repaired and trailing quarantined row counts. This policy never excludes a line because a repair occurs in its future.

Run from `C:/atx/atx-db`, with `PYTHONPATH=src`, `OPENBLAS_NUM_THREADS=1`, and `ATX_ALPHA_PANEL_STAGE=panel_goldready`. Data commands should run under `.superpowers/sdd/tier1-parity/run_memory_guarded.py` with a 1 GiB cap. The production pipeline orchestrator waits for the complete refreshed silver stage before these steps:

```powershell
.venv/Scripts/python.exe -m atx_db.alpha_panel.characteristics --years 2019-2026 --memory 560MB --threads 1 --isolate
# Strict labels and chronological evaluation are produced by labels/ic_eval.
.venv/Scripts/python.exe -m atx_db.alpha_panel.gold --ic data/alpha_panel/v1/validation/characteristics_goldready_ic.json --years 2020-2026 --memory 300MB
.venv/Scripts/python.exe -m atx_db.alpha_panel.export_impl align-stage --role <sealed-consumer-role> --out <new-fields-directory> --stage gold
```

`align-stage --stage characteristics` exports broad raw candidates if empirical admission remains unavailable. Exports retain the consumer's exact sorted date/ID axes and little-endian float64 date-major layout; absent observations remain NaN. Role manifest bindings include `dates`, `instruments`, axes hashes and the source feature manifest hash. Source-quality qualifications accompany every exported field. The role seal refuses all sessions on or after 2024-01-01. Memory-mapped matrices and calendar-month scans bound memory use without changing the binary contract.

Tests cover admission boundaries, missing evidence, validation independence, rank ties and zero fill, composite thresholds, nonmember exclusion, atomic stage publication and source hash mismatch, the consumer binary layout, missing/absent cells and the export seal. Consumer code was not modified.

# Deferred candidate proofs in final raw-price publication

This is an isolated fitting experiment following the reviewed
[700-call capture and design](cold-price-candidate-capture-review-20261024.md)
and [candidate component](cold-price-candidate-batch-component-20261024.md).
`ATX_VOL_EMPIRICAL_CANDIDATE_PROOFS` defaults to `OFF`. An enabled build uses the
existing empirical vector target evaluator only for deferred monetary candidate
proofs in final raw-price publication. It changes no public fitting policy or
scalar audit reference. The linked-library getter records the actual selection
in both effective-policy and binary build provenance.

The original re-implication body now has one shared prefix and one typed Search
tail. The prefix returns either a completed identification or an owned pending
candidate. It retains immutable identification lookup, the existing native,
economic and prepared cold proofs, and the ordinary direct-seed attempt in their
original order. Only the monetary candidate that follows those routes can be
deferred. A pending record owns its complete target/model/carry/budget request,
exact inverse options and immutable model key; no prepared-lane pointer or
borrowed floor owner survives the prefix.

The ordinary wrapper immediately executes the unchanged scalar candidate and
shared Search tail. The experimental finalizer instead collects pending records,
runs the reviewed candidate batch component once for the slice, then scatters
results to the original node/side order. Refused candidates run the same Search
tail, including rejected-root classification and genuine PriceOnly intervals.
It does not repeat the prefix, Screen inverse, successful native route or direct
seed. Request/model/local-carry/budget bindings are rechecked before an answer
can be published. The single immutable slice fixes the exact options shared by
the component call.

Four outer arrays are allocated before any prefix work. Allocation refusal at
that point keeps the complete original scalar operation; it cannot replay a
previously executed inverse. The component's separate three-buffer setup and
per-proof allocation controls retain their reviewed fallbacks. The outer
publication floor owner remains separate from the component's proof and Fast
continuation owners. Their preparation/hit counts are reported separately.
This deliberately changes cache scheduling; whole-input equivalence remains a
required gate, not an assumption derived from aggregate cache counts.

The existing candidate-attempt/root and Screen/Fast outcome counters retain
their request meanings. Separate batch counters expose calls, pending requests,
proposal/seed/continuation work, empirical/scalar proof outcomes, allocation
fallbacks and each floor owner. Component subclocks overlap its inclusive clock.
The finalization clock includes outer storage, prefix, proof, Search and owner
destruction, and overlaps the Certify bucket. These clocks must not be summed
as independent stages. The unchanged full cold-fit clock charges all work.

Private comparison controls select ordinary scalar, batched scalar proof or
batched empirical proof without adding a public policy toggle. Runtime RED
showed the requested batch modes still reported zero batch calls/requests.
The new tests compare every final row's price, status, IV, reason, interval and
queried metadata, including negative carry, strict-proof refusals that resume
Search, and a zero-width raw quote that remains FloorVol. The compiled-mode
control checks the actual linked selection. Native CLI checks join effective
policy/build provenance and the complete batch counter denominator.

One older finalizer assertion omitted the already separate prepared vector-hit
counter. The failed receipt is retained. Frozen `07025219` source has the same
assertion and the same explicit vector-versus-scalar consumption counters; this
was a source-level baseline comparison, not a rerun of an archived old binary.
The corrected equality includes that category and keeps the original 18-lane
denominator. No numerical tolerance or implementation was changed for the test.

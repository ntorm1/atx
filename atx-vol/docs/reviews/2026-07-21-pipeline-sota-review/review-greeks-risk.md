## 1. CORRECTNESS — ranked defects

**P1-1. Legacy theoretical-leg plan: greeks inconsistent with the served price on the American-cache route.** `portfolio_risk.cpp:556-597` (`PricingPlan::price_group`). Price adds the EEP overlay `F·corr->eval(...)` (:561-563) but the FirstOrder greeks are pure `black76_greeks` with only spot-measure scaling (:587-597) — no `eval_grad` terms, unlike the sibling `price_option` (`portfolio_price.cpp:211-227`) which corrects delta/vega/theta/rho with `c, c_k, c_T, c_σ`. Failure: a deep-ITM American put priced through `RoutePolicy::B76AlCache` reports the American price but the European delta/vega — a hedger off this plan under-hedges by the full EEP delta (order c−c_k, several delta points ITM). Module is DEPRECATED/test-only, so P1 not P0; but the header sells it as the reference for capabilities the canonical path lacks.

**P1-2. Legacy scenario engine ignores the correction cache entirely (and disagrees with its own module's marks).** `portfolio_risk.cpp:229-244` (`scenario_pnl`): base and shocked prices are `black76_price` only, even when a populated per-side `CorrectionCache` is bound in the same `MarketBinding` that `price_portfolio` prices with the overlay. Scenario PnL of an American book excludes the EEP change; base marks disagree with the pricing engine's marks for the identical binding. Additionally sigma is held at the base-strike value under a spot shock (pure sticky-strike, no smile roll — undocumented in the header, unlike scenario_grid which documents it), and `SurfaceTwist` is `NotImplemented`. Deprecated ⇒ P1.

**P2-1. Ok-status gate does not protect against a NaN greek with a finite price.** `portfolio_pricer.cpp:782-789` (`solve_uniques`): Ok requires only `isfinite(b_greeks[p].price)`; neither `american_greeks_al` (`american.cpp:3110-3159`) nor `american_greeks_fd` (:2940-2952) isfinite-checks the differenced greeks (an `american_price` *error* is caught; a successful non-finite stencil price or an overflowed difference is not). A NaN vega on an Ok lane poisons `PriceTotals`/`reduce_pnl_totals` (which gate on status only), violating the "no NaN enters a cell/total" promises in `scenario_grid.hpp:50` and the frame contract. The AVX2 laned kernel *does* guard exactly this (`american_greeks_avx2.cpp:221-237`) — the scalar production route is the unguarded one. Concrete scenario: extreme (S,σ,T) where a σ+hv stencil overflows to inf, base price finite ⇒ vega = inf−finite = inf, volga = NaN. Low probability, silent, book-wide blast radius. One `isfinite` sweep at the Ok-stamp site closes it.

**P2-2. Deep-wing put price inside the greeks bundle has 100% relative error.** `greeks.cpp:41` (`price = df*(K*(1−n_d2) − F*(1−n_d1))`) and the bit-matching AVX2 mirror `greeks_batch_avx2.cpp:158-163`. Same cancellation the A8 fix removed from the *price* kernel; retained here (both paths complement-form, so batch==scalar holds). d2 ≳ 8.3 ⇒ put premium computes exactly 0.0 vs true ~1e-26·df; theta/rho/charm inherit it via their `price`/`delta` terms. Absolute error ~1e-16 (economically nil), but any consumer normalizing by wing premium (log-price residuals, wing IV re-inversion off the bundle) breaks. Tests assert absolute bounds only (`simd_greeks_test.cpp` DeepWing gates are absolute) — same "invisible to the suite" trap as simd-1.

**P2-3. Fixed-carry correction-cache greeks: still no staleness tripwire.** `american.cpp:1869-1898` + `correction.cpp:801-810` ("out-of-box on an axis nulls that partial"). The cached jet evaluates a correction baked at (r₀,q₀) with the query's (r,q); rho/theta/charm/dP_dq deliberately omit ∂c/∂r, ∂c/∂q (documented), and there is still no debug assert comparing query carry vs `baked_r()/baked_q()` (core-11). Failure: an intraday rate/borrow move served through a stale cache silently mixes old-carry EEP sensitivities into new-carry B76 legs; the error is O(∂c/∂r·Δr) and invisible. Out-of-box behavior is self-consistent (clamped value, zeroed partial) but means every greek of an out-of-box query is the *edge* contract's greek — `CacheOutOfBoxClamps` counter exists; nothing surfaces it per-frame.

**P2-4. Cross-layer greek-convention seam: `Greeks` (B76, forward-based, rho = −T·P|F) vs `AmericanGreeks` (spot-based, rho includes the T·F·Δ through-forward leg).** `greeks.hpp:9-14` vs `portfolio_pricer.hpp:56-62`. Both are individually correct and documented, but the two aggregation APIs mix them: legacy `aggregate_greeks` sums **forward-delta, raw-qty** B76 greeks (`portfolio_greeks.cpp:94-117`) while canonical `PriceFrame` sums **spot-delta, qty·mult** American greeks. Same book, two entry points, deltas differing by e^{(r−q)T} per leg plus EEP — an integration hazard rather than a math error. The skew-adjust slide variable compounds it: legacy uses F as "S" (`portfolio_greeks.cpp:101-104`, documented), canonical uses true spot (`portfolio_pricer.cpp:610, 776-779`).

**P2-5. Legacy aggregation admits `NumericError` lanes.** `portfolio_price.cpp:368-386`: the aggregate gate is `isfinite(lv.price)` — a finite-but-negative price is marked `NumericError` (:240-242) yet still accumulates into value/greek buckets. Canonical path gates on status; legacy doesn't. P2 (legacy).

## 2. PERFORMANCE

- **Bundle cost vs price-only:** Marks = 1 boundary solve/unique; analytic FullGreeks = 5 (`american_greeks_al`), narrowable to 3 ({delta,vega}) / 1 ({delta}) via `greek_needs` — honored at the scalar production solve site (ledger-proven per seam doc); FD fallback = 17 stencils over 7 memoized boundaries with warm-start + shared premium cache (`american.cpp:2712-2806`) — a well-engineered fallback. Cached-correction route: greeks ≈ one tensor traversal (`eval_second_order`), effectively free.
- **Adjoint route is a cost regression today:** 0.81× vs fd_warm on the full bundle (design doc §8) — the tape's 2-sweep-per-step FD tangent + volga's 2 cold σ± re-solves; the analytic reverse sweep (the ≥5× lever) is not landed. It is opt-in A/B with no production caller, so no production harm, but the "constant-cost 8 greeks" headline is not yet real.
- **Redundant evals eliminated where it matters:** L1 base-risk stamp reuse (`pnl_*` reuse guard, `portfolio_pricer.cpp:1672-1683`) skips the 5-solve base bundle on no-churn days; `carry_base_risk_subset` extends reuse across book shrinks; adjoint route fuses mark+greeks into one solve (I-2). Remaining redundancy: `solve_uniques` adjoint arm re-runs `surf->resolve` per contract after `evaluate_batch` already resolved (:763); skew-slope adds 2 `total_variance` evals per unique (cheap).
- **Scenario grid:** Taylor cells are ~free (one FullGreeks solve amortized over the whole matrix — the right design); **Exact cells re-solve cold `american_price` per unique per cell with no warm-start** (`scenario_grid.cpp:251-252`) although `AloPricer` (fixed-contract σ-sweep warm state) exists precisely for this shape, and allocate `std::vector<double> pprime(n_unique)` **per cell inside the parallel loop** (:236) — allocation in the risk loop, contradicting the module family's allocation-free discipline. For an 11×11 grid with radii at ±3%, typically ~72 Exact cells × n_unique cold AL solves.
- **SIMD reach:** pnl Taylor AVX2 — **production-wired** (fixed). AVX2 marks boundary — **shipped Auto-ON**. Laned AVX2 American greeks — **ForceAvx2-only** at the sole surface call site (bench/A-B); production Auto is scalar. B76 greeks batch AVX2 — no production consumer on the American portfolio path (bench/python-facing).
- **Legacy paths:** O(groups) linear-scan bucket lookups and O(n²)-ish `ctx_cache` scans (`portfolio_price.cpp:277-306`) — acceptable only because deprecated.

## 3. FEATURE GAPS vs Vola-class risk

1. **No bucketed risk on the canonical path.** `PriceTotals`/`PnlTotals` are single whole-book buckets; per-underlier / per-expiry / key-rate aggregation exists only in the deprecated legacy `AggMode` machinery. No vega-by-expiry, no key-rate vega buckets, no rho ladder. This is the largest desk-usability gap vs Vola-class risk.
2. **Smile-dynamics regimes are delta-only.** Sticky-strike/sticky-delta ω-blend adjusts delta only; no smile-consistent gamma/theta, no sticky-moneyness coefficient basis for `pnl_explain`/`scenario_grid` (both strictly sticky-strike; documented for the grid, silent for legacy scenario).
3. **Dividend/borrow risk computed but not surfaced.** `american_carry_greeks{,_al,_fd}` (∂P/∂q with regime-guarded stencils) and `american_dividend_sensitivities` (∂P/∂Div_i chain, `american.cpp:3321-3334`) exist and are correct — but no `PriceFrame`/`PnlFrame` column, no portfolio aggregation, no per-discrete-dividend reprice (q_eff-chain proxy only), and cached-route carry greeks are fixed-carry. Borrow has no separate bucket from q_eff.
4. **Second-order American cross greeks: strong.** vanna/volga/charm shipped on FD, analytic-AL, adjoint, and AVX2 routes (rare vs competitors); speed internal-only; no veta/zomma/color/DdeltaDr (these currently land in `pnl_unexplained`).
5. **Scenario ladders: spot×vol matrix is first-class** (`scenario_grid` with measured Taylor radii + Exact re-solve routing + fallback accounting — genuinely Vola-class design); missing: vol-term-structure twist axis (`SurfaceTwist` NotImplemented), rate/dividend axes (dr/dt are whole-grid scalars), per-cell greek outputs, per-underlier cell decomposition.
6. **Absent entirely:** beta-weighted portfolio greeks (no beta anywhere); margin/haircut analytics (only the `assignment_risk` carry-vs-time-value heuristic, `american.cpp:3413-3439`); vol-swap/var-swap risk integration with the new surface world (`derivatives.*` is legacy-surface-typed and consumer-less).

## 5. Verdict

The canonical greeks stack (analytic-AL bundle with masked solve tiers, correction-cache jet, Taylor pnl-explain with exact residual accounting, scenario grid with measured Taylor radii) is mathematically sound — every chain rule I checked by hand is right, all four high/medium prior-review defects in this layer are genuinely fixed at the cited lines, and the bit-identity/determinism discipline is the best I have seen in a codebase this size. The top three risks are: (1) the deprecated `portfolio_risk`/`portfolio.hpp` engines still ship features the canonical path lacks while carrying real inconsistencies (European greeks against American-cache prices; scenario engine that silently drops the EEP), so anything routed there today gets wrong American risk; (2) the canonical risk output is a single whole-book bucket — no per-expiry/per-underlier/key-rate vega, no dividend/borrow columns despite correct kernels existing — which is the actual gap to Vola-class desk risk, larger than any numerical issue; (3) a thin correctness membrane at the Ok-status gate (finite-price-only) plus the fixed-carry cache contract means rare NaN greeks or stale-carry caches fail silently book-wide. Top three investments, in order: bucketed aggregation + dP/dq/dDiv surfacing in the frames (small code, large product value — kernels exist); an `isfinite` sweep + baked-carry assert at the two silent-failure seams; then either finish the first-order-tier wiring into the hedge/risk frames end-to-end and decide the laned-greeks Auto policy, or stop advertising the adjoint/laned throughput story until one of them is on the production route.

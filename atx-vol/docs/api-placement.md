**Measurement rule:** a header is **public** iff it is transitively `#include`d,
directly or indirectly, from any root translation unit under one of the external-only
roots — `atx-options-engine`, `atx-vol/python`, `atx-vol/test-package` (per the
2026-08-14 user decision: `tools/`, `examples/`, and `bench/` are internal programs and
get the private include dir, the same treatment as tests); everything else — including
all of `atx/vol/detail/**` and anything the spec forces private (test fixtures, probes)
— is **private**, and module assignment (which of `core`/`pricing`/`fitting`/
`marketdata`/`storage`/`analytics`/`backtest`/`simd` a header belongs to) is a fixed
declaration from the spec taxonomy, independent of reachability.

# Open-Data Provider Parity Matrix

Date: 2026-06-28

This tranche promotes the institutional-provider parity target into the warehouse as
`provider_parity_matrix`. The table is seeded from public documentation and maps
proprietary domains to open/public substitutes already present or planned in the
DuckDB warehouse.

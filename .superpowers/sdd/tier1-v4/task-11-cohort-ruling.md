# R16: ownership cohorts must use information visible at the snapshot

An expected-manager inventory assembled in 2026 cannot retroactively define
which managers were missing in a 2020 feature snapshot. Conversely, the set of
filers that happened to arrive cannot establish full-market coverage or buying.

Use separate named states: prior_visible_baseline_complete,
contemporaneous_arrived_complete, and retrospective_inventory_complete. The
comparison baseline is the prior report cohort actually public before the
snapshot, with visible entrants explicitly identified. Record cohort identity,
population, missing reports and every source clock. This is a qualified partial
population, not evidence of complete contemporary market representation.

Full-population ownership levels stay incomplete/missing unless independent
contemporaneous population completeness is established. Separately labeled
observed partial levels can be diagnostic. Absence from a complete filing table
can establish reported_holding_zero only after source exclusions, omission,
confidential-treatment and shared-manager ambiguity checks. It does not establish
economic ownership zero merely because the table has no row.

Changes require the same eligible manager population and complete qualified
originals at both dates, with units, mapping and splits reconciled. Filing arrival
must not become buying. Late filings and amendments create strictly clocked new
vintages and preserve earlier snapshots. Tests must cover future manager leakage,
missing quarters, entrants and late amendments. Final bronze completeness is a
separate retrospective source audit, never a historical feature input.

Ruling: adopt this explicit PIT cohort contract because historical visibility
and final recovery completeness answer different questions. Cost if wrong:
partial signals may remain missing and require more source work; the original
coverage denominator and all ownership acceptance gates remain unchanged.

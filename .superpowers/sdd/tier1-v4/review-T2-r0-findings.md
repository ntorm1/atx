### Issues — Critical / Important / Minor

Critical: 0. Important: 5. Minor: 3.

**I1 — Important: undated incorporation snapshot influences historical membership.** `atx-db/src/atx_db/alpha_panel/universe.py:183` and `:234`. `inc_snap` discards any source availability and `coalesce(ic.inc, sn.inc)` uses the current snapshot whenever no historical cover is visible. This can apply a later redomicile to earlier sessions and changes both `is_foreign_issuer` and `univ_all_common`. The fallback is not restricted to pre-2019 despite that description in the report; it applies to every missing historical cover. T1-b accepts panel/code FINRA, link and Nasdaq-directory qualifications, not this newly added issuer-incorporation snapshot. Fix: use dated incorporation history and strict availability, or give the snapshot a conservative observation floor and leave earlier incorporation unknown; add a fixture with a later foreign redomicile and no visible earlier cover. Explicit owner amendment would be required to retain an additional non-PIT exception.

**I2 — Important: SIC alone keeps operating de-SPACs excluded.** `atx-db/src/atx_db/alpha_panel/universe.py:133` and `:155`; `atx-db/tests/test_universe_stage.py:209`. The new flag is panel.is_spac OR SIC 6770, and all_common excludes it unconditionally. Concrete named-risk check outside the diff: `panel.py:315–316` deliberately uses SIC 6770 only with zero revenue, with the comment that SIC outlives the de-SPAC. A common operating line with panel.is_spac=false, positive reported revenue and a retained SIC 6770 is admitted by the imported base filter but rejected here. The fixture only permits de-SPAC membership after SIC changes to 7372, so it does not catch this case. Fix: use dated blank-check/de-SPAC status or a documented operating/revenue qualification consistent with the established panel rule, and test a de-SPAC retaining 6770. Re-measure French counts after fixing this. Do not assume the entire positive French residual is thereby solved: this defect removes names, whereas the reported later residual is an excess.

**I3 — Important: repaired broad universe and systematically biased index flags.** `atx-db/src/atx_db/alpha_panel/universe.py:225–237` and `:272`; `atx-db/docs/datasets/universe.md:322`. SC/BZX rows receive a repaired listed exchange only inside this stage, while index flags are copied from unchanged membership. Concrete named-risk check: `indexes.py:168–172` still requires panel.exchange in LISTED, so otherwise eligible Nasdaq Capital Market lines with NULL exchange are excluded before ranking. A roughly 2,000-company R2000 count can pass after selecting replacement companies and does not detect this systematic exchange exclusion; the stage's R3000 coverage table consequently describes a biased proxy. Fix upstream exchange mapping and arrange authorized panel/codes/indexes rebuilds, then rebuild universe and recompute gates/coverage. Until that dependency is corrected, retain explicit unresolved status rather than treating the proxy count PASS as substantive validation. Do not merely add repaired names to existing membership: ranks and company caps must be recomputed.

**I4 — Important: binding accuracy gate unresolved.** `atx-db/docs/datasets/universe.md:102`, `:313`; `.superpowers/sdd/tier1-v4/task-2-report.md:44`. The artifact explicitly lists 14 failed monthly observations, from −13.1% to +6.6%. T2-a specifically retains this accuracy check as the safeguard for the looser daily band. No ledger ruling provided for this review waives or assigns the French FAIL. The early shares/vendor gaps can be tracked as upstream dependencies, but the later residual is not demonstrated to require licensed CRSP: the report gives an attribution hypothesis rather than a complete class reconciliation. Fix/close internal classifier defects first, document a measured pre-2023 month-by-month reconciliation, and either repair upstream gaps or obtain a concrete carry-forward ruling. Preserve the failed manifest until the gate actually clears; changing the benchmark threshold is not a fix.

**I5 — Important: global maximum withdrawal makes BDC history depend on future rows.** `atx-db/src/atx_db/alpha_panel/universe.py:186–187` and `:235`. The loader keeps first election and the latest withdrawal across the whole lake. If an issuer has a withdrawal before the session cutoff and another withdrawal after it (for example withdrawal/re-election/withdrawal), max(withdraw_at) selects the future event; the subsequent test withdraw_at < cutoff is false and incorrectly restores BDC status during the earlier withdrawn interval. Re-election is also not represented by the global minimum election. Thus a future appended filing can revise historical flags even though each retained timestamp is compared to the cutoff. Fix: derive BDC status from the latest qualifying status event available strictly before each cutoff, or use dated election/withdrawal intervals. Add a withdrawal/re-election/future-withdrawal fixture and assert historical flags are unchanged when future events are appended.

**M1 — Minor: pooled precision hides a weak individual flag.** `atx-db/src/atx_db/alpha_panel/universe.py:341`; `atx-db/docs/datasets/universe_hand_check.json:41` (method metadata; wrong rows are i=41,43,51). The committed arithmetic is correct: 97/100 assertions, but only 9/12 ADR assertions. The pooled 95% gate as implemented is honestly reported, so this is not a false 97% calculation. It does not establish 95% precision of each flag or recall, and the mostly correct all_common/issuer strata mask known ADR false positives (PSNYW, LDTC, TIXT). Preserve per-stratum results prominently and improve the ADR classifier when its source is authorized; independently sourced dated evidence would strengthen the hand judgments currently based largely on the same issuer metadata plus public knowledge.

**M2 — Minor: validation ignores missing observations.** `atx-db/src/atx_db/alpha_panel/universe.py:322` and `:391`. French evaluates only the intersection of ours and benchmark months; R2000 measurement skips missing universe-year files. Both can PASS on an incomplete overlap if the remaining observations meet bounds. The present reported 60 months and nine reconstitutions are explicit, so this does not explain the current FAIL. Add expected-month/reconstitution coverage checks and report missing observations as FAIL.

**M3 — Minor: hand-check verdicts are not bound to the rebuilt sample.** `atx-db/src/atx_db/alpha_panel/universe.py:350` and `:587`. The gate counts the committed verdict rows without checking rule, seed, unique sample keys, strata or correspondence to the newly generated sample. A build following classification changes can retain the old precision PASS even when sample candidates change. Bind verdicts to stable sample identities and a sample/rule hash, and invalidate precision until changed rows are rechecked.

# Saved-composition target replay source review

Independent source approval for production `64c8f58c5693fcc841e8c217e09b67e371566c73` plus correction `8005bc08faf91ad5c05926561fd74ab629ef9b86`, and six postimplementation fixtures in `f7a376ea` plus that correction. This review inspected source and fixture definitions only; no compiler, market payload or performance run was used.

The baseline preserves the existing `IcComposition::finish` target ranking, tie handling, accumulation order and partial position update. Targets remain price-free weights, without drift or survivor renormalization. The optional calendar-month L1 budget charges deployment and forced membership exits before discretionary adjustment. Forced exits remain immediate even when they exceed the limit, and the excess is reported. Month reset uses the current decision session; no later-month data affects it. Temporary net exposure and actual planned gross are reported rather than silently repaired.

The optional rough return uses target at decision d over observed prices d+1 to d+2. Only endpoint source presence is required; future membership does not select observed returns. A missing, invalid or ReturnGuard-excluded held endpoint exposes its long/short/gross weight and makes the complete-day gross/net result unavailable. The observed component remains explicitly partial. Cost scenarios apply to planned changes and short target weights; this is not a self-financing book, NAV, capacity result or Sharpe estimate. Costs and incomplete tails remain separately disclosed.

One concrete finding was repaired: the initial source bounded endpoints by payload length rather than the admitted score window. Correction `8005bc08` requires endpoint strictly before `decision_end`. A seven-date payload/four-decision fixture mutates every later price and presence cell and verifies unchanged earlier results and unavailable tails. This prevents padded future payload from crossing the declared role boundary.

The wrapper validates an externally pinned saved manifest, exact file set/geometry, same-handle payload hashes, ordered axes and finite/member contracts. Optional price data must match the saved role manifest/source/axes/window and effective support. Its aggregate admission covers retained input, optional prices, validation masks/axes, metadata and O(N) replay scratch plus O(D) output. The wrapper does retain dense saved inputs; O(N) refers to mutable replay scratch, not total loaded data. Output directory creation is exclusive, CSV close is checked and the summary is published afterward with its hash. No DSL evaluation, sign fitting or validation selection is introduced.

The reviewed fixtures cover baseline bit parity with ties and exits, hand-calculated deployment/forced breach/month reset, signed missing and guarded exposure, explicit delayed returns and modeled costs, saved-artifact tampering, flat signals and bounded admission, and score-window isolation. The artifact fixture runs without optional prices; direct rough-return fixtures cover arithmetic separately. Runtime qualification and any empirical comparison remain the parent's subsequent work.
